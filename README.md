## 安装与数据保留

- Windows：完整解压 ZIP 后运行 `Fcubes.exe`。这两个历史版本的数据在程序旁的 `data` 文件夹中；升级前退出软件，将整个旧 `data` 复制到新版目录。它们尚未包含固定用户数据目录的新修复。
- Android：直接安装新版 APK 覆盖更新，保留已有数据；不要先卸载旧版。
- 这些历史版本尚不支持自动更新。

本仓库用于发布安装包和使用说明，未上传项目开发源码。
